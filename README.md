# curiosity.exe 🧪

### `Cook ideas. Ship experiments. Repeat.`

A personal playground for daily builds, random experiments, creative coding, and unexpected discoveries.

No roadmap. No boundaries. No fixed tech stack. Just curiosity turned into code.

---

## 🧠 What is this?

`curiosity.exe` is my digital workshop — a place where ideas become experiments and experiments become projects.

This repository is not limited to a particular programming language, framework, or technology. It's an evolving collection of things I build, explore, break, fix, and learn along the way.

Some projects might be useful. Some might be weird. Some might be completely unnecessary.

That's the point.

## ⚡ What you'll find here

- 🛠️ **Daily Builds** — Something new, whenever inspiration strikes.
- 🧪 **Experiments** — Testing concepts, tools, and technologies.
- 💻 **Code Projects** — Scripts, applications, utilities, and prototypes.
- 🌐 **Web Creations** — Websites, interfaces, and interactive experiences.
- 🤖 **Automation** — Small tools that make life easier.
- 💡 **Random Ideas** — Because not every idea needs a reason.
